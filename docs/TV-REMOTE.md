# TV 리모컨 조작

설정 → 이 기기 → **TV 리모컨 모드**에서 자동 / 항상 켜기 / 끄기를 선택한다. 이 설정은 기기 브라우저에 저장된다. 자동 모드는 TV 브라우저를 감지하거나 탐색 화면에서 방향키를 누르면 켜지고, 일반 브라우저에서 마우스·터치를 사용하면 해제된다.

## 조작

- 방향키: 가까운 카드·버튼으로 이동. 가로 목록은 선택한 카드가 보이도록 스크롤한다.
  - 위/아래는 가장 가까운 줄을 먼저 고르고 그 줄에서 정렬이 맞는 항목으로 간다. 고정 상단 메뉴는 페이지에 더 위쪽 항목이 없을 때만 간다.
  - 좌우는 같은 줄 안에서만 움직인다. 회차 목록처럼 오른쪽에 아무것도 없으면 멈춘다.
  - 그룹에 바깥에서 들어오면 정해진 진입점이나 현재 선택으로 간다: 상단 메뉴 → 현재 탭, 히어로 → 재생, 회차 구간 → 선택된 구간, 재생 조작부 → 재생/일시정지 버튼, 패널 → 현재 회차·선택된 자막.
  - 이어보기 카드의 정보 버튼은 그 카드에서 아래로 갈 때만 거친다. 히어로 넘김 점은 건너뛴다.
  - 첫 화면 포커스는 늦게 렌더링되는 히어로 ‘재생’도 기다렸다가 옮긴다(사용자가 아직 키를 누르지 않은 경우).
- 확인(Enter/Select): 선택한 항목 실행.
- 뒤로: 열린 패널의 하위 화면 → 패널 닫기 → 재생 조작부 숨기기 → 이전 화면 순서로 동작한다. 상세에서 돌아오면 원래 카드로 선택을 복원한다.
- 재생 중 조작부가 숨겨져 있으면 좌우는 바로 탐색 단위만큼 이동하고 재생바에 포커스를 둔다. 위/아래·확인은 조작부만 표시한다.
- 재생바 좌우와 빨리 감기/되감기 키는 막대에 목표 위치를 미리 보여주고, 누름이 멈춘 뒤 0.5초 후 한 번만 이동한다. 꾹 누르면 초당 최대 8번, 1.5초 뒤부터 3배 단위로 이동한다.
- 오프닝·엔딩 건너뛰기 버튼이 나타나면 (사용자가 다른 곳을 조작 중이 아닐 때) 포커스를 받아 확인 한 번으로 건너뛴다. 자막 설정 슬라이더는 기본 단위로 조정한다.
- 재생/일시정지/빨리 감기/되감기 미디어 키 지원. 다음 화로 넘어가도 전체화면을 유지한다.
- 상세 상단의 ‘← 뒤로’는 배경·테두리 없는 회색 글자로 표시한다. 로딩·오류 상태에서도 사용할 수 있다.

브라우저에 전달되는 Samsung Back(10009), LG Back(461)도 처리한다. 실제 TV 기기 검증은 아직 하지 않았다. TV 브라우저가 소비해서 웹페이지에 전달하지 않는 키는 제어할 수 없다.

공식 키 참고: [Samsung](https://developer.samsung.com/smarttv/develop/guides/user-interaction/remote-control.html), [LG](https://webostv.developer.lge.com/develop/guides/back-button).
