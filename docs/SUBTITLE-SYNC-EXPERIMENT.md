# 네이버 공개 자막 경로와 싱크 실험 (2026-10-05)

## 네이버 수집

공개 게시글 두 건을 PC PostView와 모바일 HTTP 경로로 비교했으며, 두 경로 모두 본문과 첨부 파일을 수집했다. 모바일 경로로 바꾸어 성공률이 개선됐다는 근거는 없으므로, 실험했던 모바일 우선 변경은 제거하고 기존 HTTP 경로를 유지한다.

실제 확인한 공개 게시글:

- 킹덤 5기 1화: https://m.blog.naver.com/chereamante/223321806160
- 라그나 크림슨 18화: https://m.blog.naver.com/nezumi99/223357055819

카이란의 네이버 블로그는 사용자가 폐쇄된 블로그라고 확인했다. 접근 제한 응답을 수집기 오류로 취급하거나 우회 대응을 추가하지 않는다. 별도 자막 브라우저 컨테이너나 브라우저 설정은 추가하지 않는다. 운영 중인 APK 브라우저는 이 변경과 관계없다.

## 범용 검색 검증 원칙

여러 작품은 공통 로직의 검증 사례로 사용한다. 테스트를 통과시키기 위해 작품별 별칭·시즌 보정·첨부 URL 예외를 추가하지 않는다. 제목 정규화, 시즌·회차 판별, 공개 게시글 탐색, 첨부 파일 해석에서 재현되는 공통 결함을 수정한다. 자료가 없거나 폐쇄된 경우와 검색 로직의 실패를 구분한다.

## 싱크 자동 맞춤 (실험)

설정 → 자막 → 자막 고급설정에서 프로필별로 켜고 끈다. 기본값은 켜짐이다. 한국어 온라인 자막에만 적용하며, 이미 원문의 시간을 유지하는 AI 번역 트랙은 다시 보정하지 않는다.

- 같은 재생 세션에 있는 영어/일본어 자막을 기준으로 대사 시작 시간을 비교한다.
- 자막 파일을 기기에서 읽고 Web Worker에서 계산한다. Gemini 호출, 음성 인식, 영상 변환을 하지 않는다.
- ASS 그림·위치 지정 간판·일부 가사 스타일을 제외한다. 최소 50개 대사, 최소 5분에 걸친 증거가 필요하다.
- ±120초 범위에서 일정한 차이를 찾는다. 앞·중간·뒤 모두 일치하고, 대사 시작 시각 일치율과 오차 및 다른 후보와의 차이가 충분할 때만 보정한다.
- 컷 차이·FPS 차이를 늘이거나 구간별로 변형하지 않는다. 판본이 다르거나 기준이 부족하면 시각을 유지한다.
- 시간 패턴이 크게 다른 후보는 자동 선택을 보류한다. 작품명이 잘못됐다는 의미 판별은 아니며, 수동으로 선택할 수 있다.
- 수동 싱크 조절이 우선한다. 보정은 현재 자막/재생 세션에만 적용하고 원본 파일이나 DB 자막 내용은 수정하지 않는다. 자동 계산값을 다른 회차에 저장하지 않는다.
- 트랙 읽기/계산은 5초 안에 끝내고, 취소·다른 회차 이동·자막 끄기 후 도착한 결과는 적용하지 않는다. 추가 팝업은 없다.

시간 패턴만으로 모든 오인식을 판별할 수는 없다. 다른 회차에도 반복되는 노래나 간판, 자막 제작자의 다른 줄 나눔 때문에 보정 불가가 나올 수 있다. 확신 없는 경우의 기본 동작은 기존 시각 유지다.

## 검증

- 단위 검사: 양수/음수/0초 차이, 대사 누락/추가, FPS 변화, 중간 컷, 반복 오프닝, 다른 회차, ASS 간판 제외, 독립 난수 30쌍의 잘못된 정렬 거부.
- 실제 파일: 최애의 아이 2기 3화의 보관된 한국어 ASS와 BS11 외국어 ASS, 453/450개 대사를 비교했다. 일치율 약 36%로 불확실 판정, 0초 유지. 한 번의 로컬 계산 약 5–8ms. 이는 일반 기기 성능 보장이 아니다.
- 브라우저: 자동 보정값 표시, 수동 초기화 우선, 기능 끄면 기준 파일 추가 요청 없음, 자동 선택 보류/수동 선택 가능, 검사 중 자막 끄기 유지.
- 스크립트: `apps/web/tests/subtitle-timing.test.ts`, `apps/web/scripts/verify-subtitle-sync.mjs`. 브라우저 스크립트는 가짜 API와 로컬 테스트 영상을 사용한다.

## 검색 검증에서 확인한 공통 수정

- 게시글의 `(終)` / `[終]` 완결 표기를 작품명에서 제외한다. 시즌·회차·극장판 판별은 유지한다.
- 제작자 보관소를 검색 중이라는 이유로 같은 블로그의 알려진 게시글 URL을 버리지 않는다. 같은 제작자에 대한 추가 작업은 해당 글과 첨부만 확인하고 보관소 전체 검색을 반복하지 않는다.
- 가상의 작품으로 정상 회차 수집, 잘못된 시즌/극장판/회차 거부, 중복 검색 방지를 검증했다. 자막 패키지 테스트 95개 및 타입 검사 통과. 실제 18조건의 성공률 향상은 아직 재측정하지 않았다.
