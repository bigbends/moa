# 재생 복구

원격 HLS/native 영상에서 치명적 오류가 발생하면 다음 스트림 후보를 시도한다. 응답이 멈춘 경우 재연결 안내를 제공하고 정상적인 일시정지·숨겨진 탭은 구분한다. 다시 시도는 현재 위치로 새 세션을 만들며 LIVE는 실시간 위치로 돌아간다.

다른 소스 선택은 묶인 작품의 시즌·회차를 제안한다. 사용자가 판본과 이어보기 위치를 확인해야 한다. 판본별 길이·장면·자막은 다를 수 있으며 선택 중에는 자동 다음 화 이동을 멈춘다.

자막 높이·싱크·끄기 설정은 재연결에도 유지한다. VTT는 cue 위치를, ASS는 렌더링 캔버스 위치를 조정한다. 큰 높이 이동은 효과를 화면 밖으로 밀 수 있으므로 원래 위치로 되돌릴 수 있다. [자막](SUBTITLES-AND-SKIP.md)을 참고한다.
