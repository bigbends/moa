# MOA v0.1.0

첫 정식 릴리스입니다. beta.2에서 확인한 기능을 정식 채널로 제공합니다.

## 주요 기능

- 새 버전 알림과 웹에서 실행하는 수동 업데이트. 자동·예약 설치는 없습니다.
- 정식·베타 채널 선택, 서명·이미지 digest 검증, 업데이트 전 백업과 상태 확인.
- 선택 기능인 브라우저 인증: Camoufox, HTTP 인증 세션 재사용, 유휴 프로세스 종료. 기본 설치에는 포함하지 않습니다.
- 지원 데스크톱 브라우저에서 Document PiP 자막과 조작 UI. 모바일 PiP 자막은 보장하지 않습니다.

## 설치 및 업데이트

- 신규 설치는 [설치 안내](https://github.com/sidetool/moa/blob/v0.1.0/docs/UPDATES.md)를 따르세요.
- beta.1/beta.2 릴리스 설치는 웹에서 이 버전을 확인하고 설치할 수 있습니다. 앱·인증 DB 스키마는 beta.2와 동일합니다.
- 기존 Git/소스 설치는 기존 업데이트 방식을 유지하며 자동 이관하지 않습니다.
- Linux, Node 22 이상, Docker Compose 2.24 이상. 앱·인증·APK·커넥터 이미지는 amd64/arm64를 제공하며 선택 브라우저 인증 이미지는 amd64만 제공합니다.
- 사이트별 확장과 사용자 데이터는 릴리스에 포함하지 않습니다.

## 배포 개선

- 버전 메타데이터만 바뀔 때 무거운 런타임 패키지 설치 캐시가 무효화되지 않도록 했습니다.
- 개발 이미지는 수동 빌드로 전환해 main 병합과 릴리스 태그의 중복 빌드를 없앴습니다.
