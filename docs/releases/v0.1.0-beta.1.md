# MOA v0.1.0-beta.1

첫 공개 베타 릴리스입니다. 기존 Git/사용자 빌드 설치는 계속 사용할 수 있으며 릴리스 설치로 자동 전환하지 않습니다.

## 주요 변경

- 정식·베타 채널, 업데이트 확인, 시간 구간을 지정한 자동 업데이트 설정을 제공합니다. 자동 적용은 기본으로 꺼져 있습니다.
- 새 릴리스 설치는 서명 검증과 digest 고정 이미지를 사용합니다. 업데이트 전 백업, 실행 상태 확인, 호환 버전 복구 및 진행 기록을 제공합니다.
- 선택 기능인 브라우저 인증은 Camoufox와 서버에 보관한 HTTP 세션을 사용합니다. 유휴 브라우저 프로세스는 종료하며 인증 세션의 유휴 보관 시간은 1시간입니다.
- 지원 브라우저에서는 Document Picture-in-Picture 창에 자막과 재생 조작을 표시합니다. 좁은 화면의 플러그인 설치 버튼 배치를 개선했습니다.

## 설치·호환성

- Linux Docker Compose 2.24 이상과 호스트 Node 22 이상이 필요합니다.
- 앱·인증·APK·connector 이미지는 amd64/arm64, 브라우저 인증 이미지는 amd64를 대상으로 빌드합니다.
- 설치 절차와 업데이트 도구 등록은 [UPDATES.md](https://github.com/sidetool/moa/blob/v0.1.0-beta.1/docs/UPDATES.md)를 참고하세요.
- 공개키는 [release-trust.json](https://github.com/sidetool/moa/blob/v0.1.0-beta.1/deploy/release-trust.json)에서 확인할 수 있습니다. 서명 키의 출처를 확인한 뒤 설치 파일 서명을 검증하세요.
- 기존 설치 이관은 미리보기로 서비스와 이미지 일치 여부를 확인합니다. 사용자 빌드를 강제로 덮어쓰지 않습니다.

## 베타의 제한

- 이 릴리스는 첫 버전 기준점입니다. 이전 사용자 빌드에서의 자동 업데이트·복구 가능성을 선언하지 않습니다(`rollbackSafe: false`). 다음 릴리스부터 버전별 호환성 검토 후 인앱 적용을 허용합니다.
- DB 스키마 또는 배포 구조가 달라지는 업데이트는 수동 이관이 필요할 수 있습니다. 구버전 이미지 복구가 사용자 데이터를 과거 백업으로 덮어쓰지는 않습니다.
- 고정 런처·호스트 Node/Docker·신뢰키 교체는 관리자 작업입니다. 모든 호스트 환경에 대한 자동 설치를 제공하지 않습니다.
- 일반 브라우저 인증 기능의 성공 여부는 사이트와 네트워크 조건에 따라 달라집니다. 설치한 확장과 사용자 데이터는 배포 파일에 포함되지 않습니다.
