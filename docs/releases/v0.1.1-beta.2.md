# MOA v0.1.1-beta.2

확장 사이트의 주소가 바뀌어도 기존 작품·회차와 시청 기록을 이어서 사용할 수 있도록 개선한 베타입니다.

## 변경 사항

- 작품·회차의 기존 ID를 유지하고, 이전 주소와 새 주소를 별칭으로 연결합니다. 프로필별 시청 기록과 이어보기 위치, 관심 작품은 그대로 보존합니다.
- 확장 설치·업데이트로 확인된 숫자 도메인, 도메인명, TLD 변경을 처리합니다. 저장소 목록을 새로고침하는 것만으로 설치된 확장의 주소를 바꾸지는 않습니다.
- 홈에서 바로 이어볼 때도 확인된 새 회차 주소를 사용합니다. 새 주소에서 영상 추출이 실패하면 기존 주소로 한 번 재시도합니다.
- 기존 Mangayomi JS·Aniyomi APK 확장 형식을 유지합니다. 확장별 추가 설정이나 새 식별자 필드는 필요하지 않습니다.
- 여러 사이트를 묶은 확장, 상대 주소, JSON·문자열 식별자, query·fragment를 구분합니다. 제목이나 회차 번호만으로 기록을 합치지 않습니다.
- 주소 변경·확장 롤백·취소된 요청·APK 자원 정리를 릴리스 회귀 검사에 포함했습니다.

## 업데이트 및 범위

- 릴리스 설치에서 **베타** 채널을 선택해 확인·설치할 수 있습니다. 설치는 사용자가 직접 실행하며 정식 채널의 최신 버전은 v0.1.0입니다.
- 첫 실행 때 주소 별칭 테이블을 추가하고 기존 기록을 연결합니다. 기존 ID나 기록을 삭제·재작성하지 않습니다.
- beta.1 데이터의 초기 변환 후 설치 실패를 가정해 이전 코드로 복구하는 검사를 통과했습니다. 주소 변경 기능을 사용한 뒤 임의로 구버전으로 내리는 경우에는 구버전이 별칭을 인식하지 못하므로 권장하지 않습니다.
- 사이트가 작품 경로·회차 식별자까지 바꾸는 경우, 다른 확장으로 이전하는 경우, 과거 중복 기록 병합은 이번 자동 처리 범위에 포함되지 않습니다. 모든 외부 사이트의 실재생을 보장하는 변경은 아닙니다.
- 브라우저 인증은 선택 기능이며, 사이트별 비공개 확장과 사용자 데이터는 배포에 포함하지 않습니다.
