# 정규 시즌 모아보기

`GET /api/media/:id/franchise`는 `{ title, seasons, complete }`를 반환한다. 시즌 항목에는 key/label/mediaId/provider/current와 확인된 season/part/seasonNumber/episodeCount 등이 포함된다. 회차가 미확인이면 episodeCount를 생략한다.

같은 승인 TV ID나 정규화된 정확한 작품 제목을 연결 근거로 사용한다. 서로 다른 승인 ID, 영화·극장판·특별편·재편집은 제외한다. 승인된 숫자 시즌이 없는 자유형 부제·아크를 임의로 매핑하지 않는다. 파이널 표기만으로 마지막 시즌 번호를 추측하지 않는다. 로컬 다중 시즌은 실제 시즌 번호를 사용한다.

전체 시즌으로 확인된 회차 수가 파트들을 충족할 때만 파트 행을 숨기며 현재 재생 중인 파트는 유지한다. 가상 예: 시즌 3 전체 22회, 파트 1 12회, 파트 2 10회가 확인되면 전체 행을 대표로 쓸 수 있다. 회차 미확인 항목은 전체 판본의 증거가 아니다.

첫 응답은 알려진 DB 후보로 구성하고 필요하면 활성 소스를 백그라운드 검색한다. `complete:false`는 탐색 중, true는 해당 탐색이 종료됐다는 뜻이다. 모든 시즌·콘텐츠를 확보했다는 보장은 아니다. 후보와 현재 작품 모두 프로필의 키즈 정책을 다시 검사한다. 수동 작품 그룹과 시즌 행의 정체성은 별개다.
