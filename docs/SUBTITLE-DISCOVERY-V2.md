# 한국어 자막 검색 보완 (2026-10-05)

첨부 realtime-subtitle 1.4.0의 검색 흐름을 비교한 뒤 독립적으로 구현했다. 첨부 프로그램의 코드와 내장 데이터는 복사하지 않았다.

## 변경

- 애니시아와 기존 보관소에 더해 작품별 제작자 경로를 검색한다. 공개 원문 페이지에서 수집한 517개 작품·제작자 연결과 출처를 `creator-directory.json`에 보관한다. 제목/별칭과 시즌이 일치할 때만 사용한다.
- 실제 검색 때 목록 원문을 다시 크롤링하지 않는다. 유지보수 시 `pnpm --filter @moa/subtitles-ko directory:update`로 갱신한다. 원문 목록은 JSON의 references에 있다.
- 일반 탐색에서 실패하면 RSS/Atom과 검색 후속 페이지를 제한적으로 확인한다. 제작자별 요청 상한 24개와 기존 동시성/시간 제한을 유지한다.
- 첨부 버튼의 data 속성과 스크립트의 URL 문자열을 읽는다. 스크립트 실행은 하지 않는다. 사설 주소 차단, 작품·시즌·회차 검증은 유지한다.
- ZIP 외 7z/RAR/TAR의 선택한 자막만 stdout으로 읽는다. 경로를 디스크에 풀지 않는다. 기본 300개 항목/40MiB 해제 크기(RAR는 선택 파일 출력 기준), 동시 디코더 2개, 프로세스별 256MiB 주소 공간/CPU 8초/실행 8초 제한을 둔다. 암호화와 링크 항목은 사용하지 않는다. 중첩 압축은 지원하지 않는다.
- 사이트 접속 차단과 시간 초과를 빈 검색 결과와 구분한다. 응답에는 원시 오류/다운로드 토큰을 싣지 않는다.
- 기존 자막 시간 정보와 ASS 스타일을 유지한다. 자동 싱크 분석은 이번 변경에 포함하지 않았다.

## 실제 외부 검색 비교

같은 서버에서 캐시 없이 확인한 단일 실행 결과이며 외부 사이트 상태에 따라 달라진다.

| 작품 | 이전 | 보완 후 |
| --- | --- | --- |
| 의매생활 1기 1화 / Gimai Seikatsu | 6.59초, 0개 | 10.01초, 냥키치 한국어 VTT |
| 최애의 아이 2기 3화 | Sydeny·카이란 ASS | 두 제작자 ASS 유지, 7.62초 |
| 주술회전 1기 1화 | 네이버 HTTP 403, 0개 | 차단 계속, 7.82초, 차단 원인 안내 |

네이버의 서버 접속 차단, 삭제·비공개 자막은 여전히 실패할 수 있다. 브라우저에서 직접 요청하는 첨부 프로그램과 성공률이 완전히 같다고 보장하지 않는다. 새 검색 경로를 모두 사용하는 실패 사례는 기존보다 시간이 늘어날 수 있으나 전체 제한을 유지한다. 성공 결과 캐시 버전을 v4로 올렸다.

## 검증

자막 패키지 93개 테스트, 서버 기존 161개 테스트와 추가 동시 검색 진단 테스트, 웹·서버 타입 검사를 확인했다. Docker에서 합성 자막으로 7z/TAR/RAR의 회차 선택과 다른 회차 거부도 확인했다. 재검증 스크립트는 `packages/subtitles-ko/scripts/verify-archives.mjs`다.
