# 어린이 프로필

키즈 프로필은 승인된 TMDB 연결의 관람 등급을 사용하며 서비스 내부의 12세 이하 정책으로 필터링한다. 성인 표시와 높은 등급은 차단한다. 알 수 없는 등급·미연결 정보는 보수적으로 처리한다. 등급이 비어 있고 Family/Kids 장르가 확인된 경우 예외적으로 허용하며 Animation 장르만으로 허용하지 않는다.

이 정책은 국가별 법적 등급의 동등성이나 연령 적합성을 보장하지 않는다. 원격 메타데이터 오류·미분류·소스의 잘못된 종류가 결과에 영향을 줄 수 있다. 보호자는 허용 소스와 연결 메타데이터를 직접 확인한다. 카탈로그·검색·상세·시즌·재생 요청에 정책을 적용하며 계정 간 격리는 [계정 정책](ACCOUNTS.md)을 따른다.
