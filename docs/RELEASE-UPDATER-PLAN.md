# 업데이트 기능 범위

사용자가 원하는 흐름은 새 버전 알림 → 웹에서 설치 확인 → 진행 상태 → 재접속과 결과 확인이다.

- 관리자가 정식/베타 채널을 선택한다. 호스트가 약 6시간마다 확인한다.
- 설치는 명시적인 사용자 요청으로만 진행한다. 예약/자동 설치 기능은 제거했다.
- 알림은 작고 비차단 방식이며, 닫으면 24시간 쉬고 다시 보지 않음을 선택하면 알림을 끈다. 설정에서 다시 켤 수 있다. 계정·서버별 해당 브라우저에 저장한다.
- 기존 Git/Docker 호스트 업데이트 연결을 유지한다. 별도의 기존 설치 이관 기능은 제거했다.
- 신규 릴리스의 서명 확인·백업·health 확인·호환 이미지 복구는 데이터 보호를 위해 유지한다. DB를 과거 시점으로 자동 덮어쓰지는 않는다.
- UI/UX 설계는 지정된 UI 담당에게 맡기고, 메인은 서버 동작과 실제 계약을 검토한다.

공개 릴리스 발행과 운영 배포는 아직 수행하지 않았다. 구체 설치 안내는 UPDATES.md를 따른다.
