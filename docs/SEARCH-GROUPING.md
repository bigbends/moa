# 검색과 작품 묶기

설정의 작품 묶기를 켜면 같은 작품으로 확인된 카드들을 하나의 그룹으로 표시한다. 소스별 검색은 독립적으로 진행하며 먼저 도착한 결과부터 그룹을 해석한다. 그룹 해석 실패 시 원본 카드를 표시한다. 끄면 원본 소스 카드를 유지한다.

승인된 TMDB 식별자·미디어 종류·시즌·파트·제목 정체성을 함께 사용한다. 서로 다른 승인 ID, 영화/시리즈, 특별편/정규 시즌, 더빙/자막 판본을 제목이 비슷하다는 이유만으로 합치지 않는다. 잘린 제목이나 미확정 회차를 임의로 보완하지 않는다.

예를 들어 가상 소스 A와 B가 모두 `예제 여행 시즌 2`의 같은 승인 TV ID를 제공하면 그룹 후보가 된다. `예제 여행 극장판`이나 `예제 여행 시즌 3`은 별개다. 사용자는 상세 화면에서 수동 묶기·분리·초기화를 선택할 수 있고 결과는 프로필에 저장된다.

`POST /api/media/groups/resolve`는 `{ "ids": ["example-a", "example-b"], "query": "예제 여행" }` 형태로 요청한다. 실제 존재하는 미디어 ID만 사용한다. 대표 카드와 원본 소스 목록은 재생 선택을 위한 정보이며 모든 판본의 길이나 자막이 같다는 뜻은 아니다. 시즌 모아보기는 [별도 정책](FRANCHISE-SEASONS.md)을 따른다.
