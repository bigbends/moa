# 캐시와 상태

소스 목록·검색·상세는 제한된 SQLite 캐시와 동일 요청 병합을 사용한다. fresh 결과를 재사용하고 허용된 stale 결과는 먼저 반환한 뒤 백그라운드 갱신한다. 완결 판단이 확실한 상세는 오래 보관하고 회차 변화가 관측되면 짧은 정책으로 돌아간다. 실패를 정상 결과처럼 영속 저장하지 않는다.

이미지는 원 URL·헤더·크기 또는 로컬 파일의 변경 정보를 기준으로 WebP를 생성하고 디스크 LRU 예산을 적용한다. 설치·설정·네트워크 변경은 관련 캐시를 무효화한다. TTL·용량은 구현 상수이며 외부 서비스 이용 조건보다 우선하지 않는다.

`GET /api/admin/cache-stats`는 관리자용 hit/miss·외부 호출·자원 상태를 제공한다. DB·운영 응답·개별 URL이 포함된 진단 출력은 private 경로에 둔다. 공유 캐시는 계정 접근 권한과 키즈 정책을 대체하지 않는다. 시청 기록·자막 선택·진행 중 세션은 캐시 삭제와 구분한다.
