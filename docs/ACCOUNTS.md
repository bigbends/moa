# 계정과 프로필

인증 서버는 관리자·일반 계정과 로그인 세션을 관리한다. 최초 관리자는 [배포](DEPLOYMENT.md)의 대화형 스크립트로 생성한다. 기존 관리자의 비밀번호 재설정은 같은 스크립트에 올바른 인증 DB를 지정한다. 관리자 화면에서 초대를 발급하고 계정 상태를 관리한다.

계정은 인증 경계이고 프로필은 시청 기록·찜·개인 설정의 구분이다. 다른 계정의 프로필이나 재생 세션에는 관리자도 접근할 수 없다. 카탈로그와 다운로드 캐시는 공유한다. 전역 소스·라이브러리·자막 삭제·번역 설정은 관리자 전용이다.

gateway는 요청자가 보낸 계정 헤더를 제거하고 인증 결과로 덮어쓴다. 앱 포트와 인증 서버는 외부 클라이언트가 우회 접근할 수 없어야 한다. 계정 DB·bootstrap credentials·CSRF secret·초대와 세션 토큰은 비공개 자료다. HTTPS origin에서 Secure 쿠키를 사용한다.

백업에는 앱 DB와 인증 DB를 함께 포함한다. 계정·프로필 FK와 APK 데이터가 연관되므로 선택한 테이블만 복사하는 방식으로 이관하지 않는다. [보안 제보](../SECURITY.md)를 참고한다.
