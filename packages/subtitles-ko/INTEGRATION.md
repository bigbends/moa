# 자막 통합

서버는 에피소드·프로필에 대해 후보를 조회하고 searchId/candidateId로 선택을 검증한다. 선택한 파일을 변환·캐시한 뒤 접근 토큰을 발급하며 재생 세션의 자막 목록에 연결한다. 임의 URL을 그대로 다운로드하는 공개 API를 만들지 않는다.

시즌·회차·episodeOffset은 확인된 정보만 전달한다. 자막 후보의 점수는 권리·내용·판본 일치 보장이 아니다. 크기·압축·경로·취소 제한을 유지하고 실패 시 기존 트랙을 보존한다. [API](../../docs/API.md), [자막 정책](../../docs/SUBTITLES-AND-SKIP.md)을 따른다.
